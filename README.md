# Bright Future Secondary School Website

**Course:** BSIT1101: Web Authoring  
**Activity 3:** Design your Home Page  
**University:** University of Kisubi

## Pages Included
- `index.html` – Home Page
- `about.html` – About Us
- `admissions.html` – Admissions
- `contact.html` – Contact Us
- `styles.css` – Shared stylesheet

## Features
- Custom SVG school logo (sun + open book + BF)
- Fully responsive design
- Real Ugandan school imagery
- Working multi-page navigation
- Clean, modern educational design

## How to view
Open `index.html` in a browser or use a local server.
